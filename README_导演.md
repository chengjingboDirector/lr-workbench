# 第四场工作台｜导演说明（V0.7 r3-3）

## 好处
- 一屏一个决定：顶栏永远告诉你「下一步」点哪里；全页只有一个实色按钮。
- 看完视频直接在那一段下面写「哪里不对」，2 秒内出新版本提示词，改了哪几句、还差什么都写在结果卡上。
- 摄影和灯光的固定项（机器、镜头型号、滤镜、焦外、炫光、暗角、紫边、呼吸、对焦、灯光效果）每段都写进正文；缺一项就不让复制。
- 英文台词逐字照剧本；屏幕字一律后期叠加。

## 导演怎么用
1. 打开页面，读剧本；想直接试，点「直接去复制提示词」。
2. 每段一个「复制这段提示词」。复制后去生成视频的网站粘贴。
3. 看完视频，在那一段的框里写大白话（比如「第 3 秒太急，光太亮」），点「提交并重新合成」。有几种改法的，系统会请你点选一种。
4. 碰到台词、剧情事件、伤和物件状态、场尾的改动，系统不会直接改，会放进「等导演确认的改动」，你点一次「确认这组」才生效。
5. 团队改剧本字只算提议，会出现在剧本卡顶部，你点「接受」或「拒绝」。
6. 俯视图上方可以点镜号「只看一镜」；图和草图看过没问题点「这张图可以」「本段草图可以」，镜头数据一改确认自动失效。
7. 标着「总监代选｜待导演确认」「总监代填｜待视听确认」「视听代填，待摄影确认」的，都是别人替你先填的，等你或岗位确认。

## 团队怎么用
- 右上角「我是」切到自己的岗位：只看到自己那一栏和自己的待办（这只是切换视角，不验证身份）。
- 写进不归自己的栏，会转成给对应岗位的建议，不直接生效。
- 导演替你的岗位改了东西，你的待办里会有「复核导演代改」，点「同意」或「不同意」；不同意会回到导演待办。
- 「这镜可以」只有导演能点；摄影负责确认挂载值、视听推导值、俯视图和草图。

## 手动交接
- 页尾「保存交接包」→ 选交给谁 → 下载一个 .json 文件，自己发给对方（页面不会自动发送）。
- 对方点「导入交接包」，先看预览，确认后待办出现。如果对方本机也改过，会提示「分叉了」。
